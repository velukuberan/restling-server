## Processing

The source dataset contains 1,000,000 password entries.

The distributed blocklist was generated by:

1. Applying Unicode NFC normalization.
2. Retaining passwords containing 15–64 Unicode code points.
3. Applying Unicode `casefold()` followed by NFC normalization.
4. Removing duplicate entries.
5. Sorting the resulting entries.

The final blocklist contains 5,329 entries.

## Limitations

This is a curated common-password blocklist, not a comprehensive database of compromised credentials.

The list must be reviewed periodically and updated through version-controlled application releases. Password validation must fail explicitly if the packaged blocklist cannot be loaded.
